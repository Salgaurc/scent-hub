# Scent Hub

Scent Hub is a full-stack e-commerce platform focused on fragrance products.

## Project Goals

The goal of this project is to build a modern online perfume store where users can:

- Browse fragrance collections
- Search and filter products
- View product details
- Add products to cart
- Create an account and authenticate
- Place orders securely
- Manage their profile and order history

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Additional Services
- JWT Authentication
- Cloudinary (image storage)
- Stripe (payments)
